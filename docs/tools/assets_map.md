# Asset Directory Map — Spellion

```
assets/
├── audio/
│   ├── rf_sfx_database/   ~500+ sonidos brutos (sin curar)
│   │   ├── Events/        magia, eventos sobrenaturales
│   │   ├── Hit_Death/     impactos, muertes, gritos
│   │   ├── Int/           interface UI
│   │   ├── Moves/         pasos, movimiento, ropa
│   │   └── Places/        ambientes (viento, bosque, mazmorra)
│   └── sfx/               sonidos curados y nombrados del juego
│
├── textures/
│   ├── ui/                iconos de HUD (SVG)
│   ├── items/             iconos de inventario (armas, gemas, pociones)
│   ├── floor/             texturas de pisos (pasto, roca, dungeon)
│   ├── enemies/           texturas de enemigos (spider)
│   ├── fx/                decals de sangre, splatters
│   └── characters/        texturas de Howard (cuerpo, cabeza)
│
├── models/
│   ├── weapons/           modelos 3D de armas (arrow, sword, bow_world, etc.)
│   ├── enemies/           spider (glb + textura png)
│   ├── characters/        Howard (fbx, glb, obj — multiple LOD)
│   └── visitantes/        decorativas: trees, bushes, plants
│
├── meshes/                recursos de malla reutilizables (.tres)
├── shapes/                collision shapes pre-hechas
├── stats/                 recursos de stats de personaje (.tres)
├── shaders/               shaders (.gdshader: palette_swap, bar_fill)
├── fonts/                 AmazDooMLeft.ttf (Doom-style)
├── env/                   entornos (sky, ambiente de bosque)
└── saved_references/      capturas de referencia (.png)
```
